# Kamra Ta Muse Worlds Tracker — automated scores and fixtures

The static GitHub Pages website reads `data.json`, refreshed from PandaScore.

## Configuration

- Add the repository Actions secret `PANDASCORE_TOKEN`.
- Optionally set the Actions variable `PANDASCORE_SERIES_ID`; it defaults to `11014`. The script does not auto-detect the series.
- The active workflow is `.github/workflows/update-scores.yml`.
- It requests `contents: write` and commits updated `data.json` to the default branch.

## Update cadence

The workflow is scheduled hourly at minute 17 UTC (`17 * * * *`).
GitHub scheduled events can be delayed or dropped; this is not a guaranteed hourly delivery service.
The browser reloads `data.json` every 60 seconds while the page is open.
The updater currently makes one API request, fetching up to 100 series matches.

To run manually, use Actions → Update PandaScore data → Run workflow.

## Automatic population and advancement

The index matches PandaScore opponent names, acronyms, and slugs to the tracker's team list.
Known opponent pairs fill empty fixture slots. Existing filled slots are preserved.

- Play-In fixtures and scores use named bracket roles rather than chronological position.
- Finished Play-In results advance winners and losers into empty downstream slots.
- PandaScore's “Group Stage” tournament is recognized as Swiss.
- Swiss opponents fill empty matchups; finished results update records and qualification status.
- Swiss round-one entrants can fill an empty standings slot.
- Knockout fixtures preserve pending positions, and finished results advance winners.

TBD matchups remain pending until PandaScore supplies both recognized opponents.
Swiss draws are supplied by the feed, not generated by the tracker.
Unknown teams need a matching team entry or alias in `trackerShortForOpponent()`.
The index includes IG among the 15 direct Swiss teams and reserves one slot for the Play-In entrant.

## Admin state

Public visitors use the published state or default presets. Admin mode (`?admin=1`) can load older browser-local data.
The IG migration fills an empty lineup slot; it does not replace a full lineup or restore a missing saved team entry.
Use “Published data restored”/the reset control to restore published defaults when old admin data is stale.
Review existing manual fixtures if they were populated by an older build: filled slots are not overwritten automatically.

## Troubleshooting

- Missing token: check the `PANDASCORE_TOKEN` Actions secret.
- Wrong event: check the configured series ID and the series metadata in `data.json`.
- Push rejected: inspect Actions write permissions and branch protection.
- Stale feed: inspect scheduled run history separately from successful fetch/commit steps.
- Missing matchup: check whether both opponents are present in `data.json` and resolve to known teams.
